# Jesoamaka Agugo — Combined portfolio

Buildless HTML, CSS and JavaScript portfolio combining customer success management, onboarding and implementation, and technical support. This directory is the complete deployable public site. It uses no backend, tracking or build dependencies.

## Local preview

Serve this directory with any static HTTP server. Open `index.html` directly for offline reading; optional Google Fonts fall back to Georgia and Arial when unavailable.

## Content

- Customer success management: complaint recovery, retention and training.
- Onboarding and implementation: NovaBuk example and illustrative rollout planning.
- Technical support: Complete ICT experience and illustrative diagnostics.
- Actual professional experience is identified separately from illustrative samples.
- The portrait is included locally. Résumé links open the existing public portfolio downloads.

## Direct links for outreach

Append `#customer-success`, `#implementation` or `#technical-support` to the published homepage URL. `#work`, `#experience`, `#resume` and `#contact` are also available.

## Existing portfolios

This is a separate combined site. Existing Netlify portfolios and the original GitHub Pages implementation homepage are preserved. Do not redirect or replace those URLs without a separate decision.

## Sources

## Editing

Edit `index.html` for content, `style.css` for presentation and `app.js` for small interactions. Keep illustrative sample labels and avoid implying sole ownership of retention outcomes or engineering fixes.
