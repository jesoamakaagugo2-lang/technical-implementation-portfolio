## Maintenance

The site uses plain HTML and CSS. GitHub Pages publishes from the root of the `main` branch. Edit `index.html` for content or `style.css` for presentation. Keep the PDF filename the same when replacing the downloadable résumé.

The two telephony work samples are illustrative. The NovaBuk example describes professional experience.
